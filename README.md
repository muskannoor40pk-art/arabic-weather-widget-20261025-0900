### 📖 Overview
The Weather Widget (Arabic Edition) is a lightweight, high-performance dashboard designed specifically for users in the GCC region. It provides an intuitive interface to check current conditions, hourly trends, and 5-day forecasts. Built with a "plug-and-play" philosophy, this project uses realistic demo data to showcase a polished UI without the complexity of external API dependencies.

### ✨ Features
*   **RTL-Optimized UI:** Fully responsive layout designed for Right-to-Left languages.
*   **Modern Aesthetic:** Clean, minimalist design utilizing glassmorphism and soft shadows.
*   **Search Functionality:** Intuitive city search simulation.
*   **Detailed Forecasts:** Visual representations of hourly changes and a 5-day outlook.
*   **No API Keys Required:** Pre-loaded with realistic, high-fidelity demo data for immediate testing.
*   **Performance First:** Built with pure Vanilla JS and CSS, ensuring lightning-fast load times.

### 🌍 Localization Notes
*   **Language:** Primary interface in Arabic (Modern Standard), with English support.
